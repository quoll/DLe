# DLe — Description Logic (Extended)
# This document uses standard Description Logic (DL) syntax for ontology axioms, with the following extensions:
#
# Annotations (lines beginning with @):
# @label <IRI> "text"  — display name of the resource
# @doc <IRI> "text"  — description of the resource
# @db <IRI>  — resource appears explicitly in the database using its own identifier; resources without @db do not
# @db <IRI> "identifier"  — as above, but queried using this identifier
# @storage <IRI> "text"  — describes database storage details
# @ann <IRI> <annotation-property> "text"  — annotation using the given property
# @prefix <prefix>: <namespace>  — declares a prefix
# @import <IRI>  — imports another ontology
# @ontology <IRI>  — declares the ontology IRI
# @version <IRI>  — declares the ontology version IRI
#
# Naming conventions:
# - Every entity has an implicit label equal to its identifier unless @label is declared
# - Unprefixed names (e.g., Application) are in the default namespace (:Application)
# - Prefixed names use declared prefixes (e.g., xsd:string) 
# - All standard prefixes are implicitly declared: owl, rdfs, rdf, xsd, skos, dcterms
# - Class identifiers conventionally begin with an upper-case letter; role, field and predicate identifiers with a lower-case letter.
#   A punned IRI is one name in both uses, so it can follow only one of these.
#
# Assertions:
# a : C  — a is an instance of C; C(a) in FOL
# (a,b) : r  — a is related to b by the role r; r(a,b) in FOL
#
# DLe extensions:
# name[facet ⊓ …]  — narrows a datatype: xsd:integer[≥1 ⊓ ≤40], xsd:string[matches "[A-Z]{3}"]; matches is xsd:pattern
# C ⊑ key(r₁,…,rₙ)  — r₁…rₙ together identify an instance of C (owl:hasKey)
# ∃r₁,…,rₙ.p  — predicate restriction: p(v₁,…,vₙ) holds for some values vᵢ of rᵢ
# ≝  — defines a predicate (lower-case) or a class (upper-case, usable in DL axioms). The right-hand side is
#      FOL, arithmetic or function calls; FOL quantifiers take parentheses, ∃x (φ). A variable may stand in a
#      class or role position, as in p(r) and p(s,o). ⟨s,p,o⟩ is an RDF 1.2 triple term, <<( s p o )>> in Turtle,
#      which names a triple without asserting it; p(s,o) asserts it.
